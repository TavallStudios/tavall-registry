# tavall-registry

Standalone Tavall Java module providing core infrastructure capabilities.

## Source of Truth & Development

- `TavallStudios/tavall-registry:main` is canonical for code, releases, tags, issues, and pull requests.
- Ordinary development occurs directly in this repository on topic branches (`working/<topic>`).
- Cross-project engineering and Git workflow policy is governed by [Tavall Docs](https://github.com/TavallStudios/tavall-docs).
- Validate locally with `./gradlew check` (Java 25).
- See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed contribution guidelines and workflow instructions.
